## Goal

MCP server locale in Go per esporre le API intervals.icu a Claude Code, abilitando query e mutazioni su activities, wellness, events e athlete fitness direttamente da conversazione.

## Context

- Nessun prior art Go serio (unico `shoeper/gointervals-mcp` a 0 stelle, greenfield)
- Reference scope: `mvilanova/intervals-mcp-server` (Python, 228 stelle)
- intervals.icu API ha OpenAPI spec completo: https://intervals.icu/v3/api-docs
- Auth: HTTP Basic, username letterale `API_KEY`, password = API key atleta
- `athlete_id = "0"` -> self-resolve lato server

## Approach

**SDK:** `github.com/mark3labs/mcp-go v0.48.0` (stdio transport)
**Config:** env `INTERVALS_API_KEY` (required) + `INTERVALS_ATHLETE_ID` (optional, default "0")
**Rate limit client-side:** 3 req/s + backoff esponenziale su 429/5xx (3 retry)
**Typing:** tollerante, `json.RawMessage` sui campi volatili (schema backend cambia)

## Risks / gotcha

- `workout_doc` schema non banale per `create_event category=WORKOUT`, v1 accetta raw JSON dal chiamante
- Rate limit non documentato, conservativo (3 rps)
- Schema volatile, `raw_response` come stringa JSON per campi non critici
